# AGENTS.md

## Проект

TaskFlow Lab — список задач на чистых HTML, CSS и JavaScript. Сборки, npm и зависимостей нет.
Открыть: `index.html` в браузере. Весь код — в `app.js`, стили — в `style.css`.

## Как устроен app.js

- Разделы идут в порядке: КОНСТАНТЫ, СОСТОЯНИЕ, ЭЛЕМЕНТЫ, ХРАНИЛИЩЕ, СЕТЬ,
  ИЗМЕНЕНИЕ СОСТОЯНИЯ, РЕНДЕР, ОБЩАЯ ТОЧКА, ОБРАБОТЧИКИ, СТАРТ. Новый код — в свой раздел.
- Данные меняются только в разделе ИЗМЕНЕНИЕ СОСТОЯНИЯ, и каждая такая функция заканчивается `update()`.
- Задачи хранятся в `localStorage` по ключу `taskflow-lab:tasks`, массивом. Ключ и формат не менять.

## Безопасность

- Текст задач и всё, что пришло с сервера, вставляем в страницу только через `textContent`.
  `innerHTML` разрешён только для очистки: `list.innerHTML = ''`.

## Чего не делать

- Не добавлять библиотеки и не подключать скрипты с CDN.
- Не делать коммиты и не запускать git: историю ведёт человек.
