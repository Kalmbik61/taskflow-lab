# График смен через ВКонтакте

1. Найди обработчик сообщения или действия во ВКонтакте, серверную проверку прав, чтение и запись Excel и расчёт числа выходящих на смену. Опиши путь конкретной операции от команды до результата.
2. Выясни структуру книги по коду и обезличенному примеру: листы, идентификаторы сотрудников, даты, формулы и обозначения статусов. Не угадывай правила включения дня увольнения или окончания вахты, границы отпуска, часовой пояс и приоритет пересекающихся статусов. Если код и пример не дают ответа, уточни спорное правило перед изменением расчёта.
3. При изменении записи проверь права на сервере и однозначность сотрудника, даты и смены. Меняй только нужную запись; сохраняй формулы, форматирование и остальные листы. Повтор одной команды не должен создавать дубль или повторно уменьшать счётчик. При ошибке записи не сообщай об успехе.
4. Проверяй на отдельной копии книги с вымышленными данными. Для больничного возьми смену с двумя сотрудниками: после отметки одного сотрудника число выходящих должно стать 1, повтор команды оставляет 1, соседние даты сохраняются. Для отпуска проверь обе границы периода; для увольнения и окончания вахты — последний рабочий день и следующий день по правилам предприятия. Проверь отказ для пользователя без прав.
5. Сообщи, какую команду и какой результат проверил, какие правила подтвердил и какие проверки остались. Не подключай рабочее сообщество и не изменяй рабочую книгу без отдельного запроса. Не коммить реальные графики, персональные данные или токены.

Пример вызова: «Используй $vk-shift-schedule. Проверь, что команда больничного исключает сотрудника только из нужной смены».
