# Проверка четырёх состояний экрана

Любой экран, который ждёт данные, должен показывать четыре состояния: загрузка, пусто, ошибка,
успех. Этот скилл проверяет, что все четыре есть и не перекрывают друг друга.

## Шаги

1. Найди в проекте каждое место, где код ждёт данные: `fetch`, чтение `localStorage`.
2. Для каждого места найди, что видит пользователь:
   - **загрузка** — что показано, пока ждём, и где это выключается;
   - **пусто** — что показано, если данных нет (пустой массив);
   - **ошибка** — что показано, если запрос упал или `response.ok` ложно;
   - **успех** — что показано, когда данные пришли.
3. Проверь, что загрузка выключается в `finally`, а не только в ветке успеха.
4. Проверь, что после ошибки и повторной удачной попытки старая ошибка исчезает.

## Что выдать

Таблица: место в коде → четыре состояния → «есть / нет / с ошибкой» и строка кода.
Ничего не исправляй. Код не меняй, git не запускай. Только отчёт.
