# TaskFlow Lab

Маленькая копия TaskFlow для занятий по Git и работе с агентом.

## Что умеет

- Добавить задачу, отметить выполненной, удалить
- Задачи сохраняются в `localStorage` и переживают перезагрузку страницы
- Кнопка «Загрузить примеры» берёт пять задач с jsonplaceholder

## Стек

HTML, CSS, JavaScript (ES6+), localStorage, fetch

## Запуск

Открыть `index.html` в браузере. Сборки и `npm install` нет.

Удобнее через Live Server в VS Code: правой кнопкой по `index.html` → Open with Live Server.
Тогда страница сама обновляется после сохранения файла.

## Ветки

- `main` — рабочее приложение
- `task/...` — подготовленные состояния для задач занятий. Условие задачи даёт преподаватель
