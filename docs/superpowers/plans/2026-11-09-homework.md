# TaskFlow Lab — домашнее задание

Рассмотрели фильтры со счётчиками, редактирование и перенос задач через JSON. Выбрали фильтры: они дают полезный результат и учат отделять отображение от данных, не меняя формат хранения.

1. В index.html добавить группу кнопок, в style.css выделить выбранную. В app.js фильтровать только вывод и пересчитывать счётчики в render после каждого изменения.
2. Проверить добавление, завершение, возврат, удаление, загрузку примеров и повторное чтение localStorage.
3. Добавить проектный навык для сопровождения связки ВКонтакте → сервер → Excel. Использовать вымышленные записи в примерах.
4. Опубликовать ветку dz-filters-vk-skill; main не менять.
